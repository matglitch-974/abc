# AGENTS.md — dépôt bcai

Ce dépôt installe et documente une instance organisée de Claude Code.

- Toute demande d'installer, de configurer, d'adapter ou de désinstaller cette instance, quelle que soit sa formulation, suit `SETUP.md`.
- Pour modifier le projet lui-même : la référence est `docs/`. Toute évolution du système doit y être documentée (comment et pourquoi), sans aucune donnée personnelle.
- Les règles de l'instance installée sont dans `skeleton/ai/AGENTS.md`.
